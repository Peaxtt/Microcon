## C. Homing (STATE_CALIBRATE)

**C1. หา Home ยังไง?**
> [X] เคลื่อนจนชน proximity/magnetic sensor แล้วหยุด
> [ ] เคลื่อนจนชน mechanical stop แล้วหยุด (current spike detect)
> [ ] อื่นๆ: ______

**C2. ทิศที่ Motor หมุนตอน Homing เป็นทิศไหน?**
> [ ] Forward (DIR=HIGH)
> [X] Reverse (เนื่องจากในโค้ดตั้ง motor_speed_cmd = -0.1f)

**C3. ความเร็วตอน Homing ที่ต้องการ?**
> 10 % ของ max speed (ปัจจุบัน hardcode ไว้ที่ 0.1f) ล้วก้ fine tune เพื่อที่จะเช็คอีกก้ได้ แต่ต้องไม่เสียเวลาเกิน เช่นถ้าถึงแล้ว ให้ขยับออกแล้วเข้ามาใหม่แบบช้า โดยออกไปนิดเดียวไม่ต้องเยอะจะได้ไม่นาน

**C4. หลัง Home แล้ว ตำแหน่ง 0 อยู่ที่ไหน? ระบบเริ่มทำงานต่อยังไง?**
> เราจะให้ตำแหน่ง home เป็น องศาที่กำหนดได้ เพื่อที่จะให้ตัวเองวิ่งไปตำแหน่ง 0 องศาจริงๆ หลังจาก home เสร็จ เพราะน่าจะต้องมี offset แน่นอน หลังจากโฮมจะวิ่งไปที่ 0 องศา และรอการทำงานต่อไป เอนโค้ดก้จะเข้าใจว่าตัวเอง home แล้วรีเซ็ตตัวเอง หลังจาก home แล้ว ค่าบนบอร์ด จะถูก log ไว้ว่าเคย home แล้ว ทำให้ถ้าเปิดเครื่องใหม่อาจจะไม่มีค่านี้ แล้วต้อง home ถึงจะไป stage ถัดไปได้อะไรประมาณนั้น
