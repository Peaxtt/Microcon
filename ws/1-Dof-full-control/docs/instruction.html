⚠️
Reed Switch Wiring: ใช้ NC contact, COM → 3V3, GPIO → Pull-DOWN. ปกติ (ไม่มีแม่เหล็ก) = HIGH. ตรวจพบ (มีแม่เหล็ก) = LOW → reed_x = 1
ℹ️
HOME_SENSOR: PNP proximity → Opto-isolator → PB6. Active HIGH (GPIO_PIN_SET = detected). EXTI rising edge. เปิดเฉพาะตอน homing เท่านั้น.
⚠️
ESTOP (PB13): Active LOW. PULLUP. ต้องกดค้างพร้อม RESET_BTN จึงจะออกจาก STATE_EMER ได้.

🚀 4. Flash & First Boot

  1. Build & Flash

    STM32CubeIDE → Build All → Run As → STM32 MCU C/C++ Application. LD2 บน NUCLEO จะกะพริบ 1 Hz = firmware ทำงาน.

  2. Connect PC (Modbus)

    USB-A (ST-Link on NUCLEO) → PC หรือต่อผ่าน CH340 บน PCB.
    Port: COM<x>, 19200 baud, 8E1, Slave ID=21

  3. Connect Joystick

    Xbox controller → USB-A → RP2040-Zero (USB-C). RP2040 ส่งข้อมูลผ่าน USART3 → STM32 PC10/PC11 (460800).

  4. Boot State

    เปิดเครื่องเข้า STATE_IDLE, homed=0. ไฟเหลืองติดคงที่ = ต้องทำ Homing ก่อนจึงใช้ AUTO ได้.

  5. ADC Auto-Zero

    บูตจะวัด zero-current voltage 100 ครั้ง แล้ว set cur_zero_v อัตโนมัติ. ตรวจสอบได้ผ่าน Live Expressions.

🏠 5. Homing Procedure (Two-Pass)

ℹ️
ต้อง Home ทุกครั้งที่เปิดเครื่อง (Flash persistence ยังไม่ implement). ทำก่อน AUTO ได้เสมอ.

เริ่ม Homing

  • Joystick: LT (ค้าง) + X
  • Modbus: write 0x01 = 1 (bit 0)

ขั้นตอน

  1. FAST sweep ซ้าย

    หมุนซ้าย 25% PWM (HOMING_FAST_SPEED=0.25). ไฟเหลืองกะพริบเร็ว 5Hz.

  2. Sensor triggered

    EXTI rising edge บน PB6 → debounce 1ms via ISR → หยุด → BACKOFF.

  3. BACKOFF +20° ขวา

    PID trajectory move +20° (HOMING_BACKOFF_DEG=20) เพื่อออกจาก sensor zone. ไฟเหลือง/เขียวสลับ 2Hz.

  4. SLOW creep ซ้าย

    หมุนซ้าย 1.3% PWM (HOMING_SLOW_SPEED=0.013). ไฟเหลือง pulse 1Hz.

  5. Sensor triggered → done!

    finish_homing(): EXTI disabled, encoder zeroed, cumulative_angle_deg=0, homed=1 → STATE_IDLE. ไฟเขียวติดคงที่.

⚠️
Abort Homing: กด LB บน joystick ระหว่าง homing state ใดก็ได้ → เข้า STATE_EMER ทันที.

Soft Limits

ParameterValueNote
MAX_ANGLE_DEG+540°+1.5 รอบจาก home
MIN_ANGLE_DEG−540°−1.5 รอบจาก home

Move commands ที่จะเกิน limit จะถูก reject ทันทีใน start_move_deg()

🔄 6. State Machine

STATE_IDLE
รอคำสั่ง. Joystick หรือ Modbus สั่งได้. homed=0 ห้ามเข้า AUTO.
STATE_HOMING_FAST
หมุนซ้าย 25% หา sensor. กด LB → EMER.
STATE_HOMING_BACKOFF
PID +20° ขวา. รอ trajectory เสร็จ → SLOW.
STATE_HOMING_SLOW
หมุนซ้าย 1.3% ช้ามากๆ หา edge ที่แม่นยำ.
STATE_MANUAL
Joystick manual motor control. Modbus jog S-curve.
STATE_AUTO
Cascade PID + Trajectory. P2P / direct move เท่านั้น. เข้า SEQUENCE ถ้า 0x22>0.
STATE_SEQUENCE
Multi-step pick/place sequence. Modbus 0x22 pair count + 0x04 gripper enable.
STATE_TEST
Precision / performance test. Modbus 0x01 bit4. เสร็จ → STATE_IDLE.
STATE_EMER
PWM=0. ออก: ปล่อย ESTOP ก่อน (ไฟ 3 ดวงกะพริบ) แล้วกด RESET_BTN.

🏭 6. Commissioning Steps (PCB ใหม่)

  1. ตรวจสาย Power

    Measure 3V3 และ 5V บน terminal ก่อนเสียบ NUCLEO. ตรวจ short ระหว่าง supply rails.

  2. Flash Phase 2 Firmware

    Update IOC → regen → restore USER CODE → build → flash. ตรวจ LD2 blink.

  3. ทดสอบ Digital I/O

    ใช้ SYS_MODE_HARDWARE_TEST (Live Expressions dev_dash.Ctrl.mode=1). Force แต่ละ output ทีละตัว. กด reed switches ทีละตัว ดูว่า bit ใน dev_dash เปลี่ยน.

  4. ทดสอบ Encoder

    หมุน shaft ด้วยมือ ดู dev_dash.Status.encoder เพิ่ม/ลดถูกทิศ. 1 รอบ = 8192 counts.

  5. ทดสอบ Motor PWM

    Set dev_dash.Ctrl.force_motor_speed=0.1 (mode=1). ตรวจทิศหมุน. ถ้าสวน → set dev_dash.Auto.motor_invert=1.

  6. ทดสอบ Homing Sensor

    ใช้ Joystick Test mode เดิน arm ผ่าน HOME_SENSOR. ดู HAL_GPIO_ReadPin(HOME_SENSOR_GPIO_Port, HOME_SENSOR_Pin) = SET ตอน blade เข้า.

  7. Run Full Homing

    Switch mode → Production. กด LT+X. ดูไฟ tower ตาม sequence. หลัง done: ไฟเขียวติด, homed=1.

  8. ทดสอบ Modbus + BaseSystem

    เปิด BaseSystem.exe. Connect COM port 19200 8E1 Slave 21. ดู heartbeat, ลอง P2P move.

  9. ทดสอบ CAN

    ต่อ TJA1050 terminal กับ node อื่น. ใช้ HAL_FDCAN_GetRxFifoFillLevel เช็ค receive. ส่ง test frame ดู ID.
